# 石墨蓝视觉方案

## 目标与范围

采用石墨灰底色、清晰的明暗层次和少量蓝色强调。依据用户对首版“太暗”的反馈，将近黑背景改为更明亮的中灰，卡片、输入区和示意图同步提亮。覆盖工作台、设备资料库、方案列表、弹窗、成像示意和 Windows 标题栏。集中管理颜色、阴影与圆角，使后续页面沿用一致规则。

## 视觉规则

- 页面底色采用中性石墨灰 `#2c3037`，导航为 `#272c33`，卡片提亮至 `#414956`，输入区为 `#2b333e`；主要内容区域不再使用近黑色块。
- 蓝色用于主按钮、选中状态、键盘焦点和视场示意；标题与型号保持灰白，正文与说明分级。
- 通过、待确认、冲突分别用青绿、琥珀和柔红表达，均保留图标与文字，避免只靠颜色传递状态。
- 统一细边框、减轻阴影与弹窗遮罩；提高正文和辅助说明的亮度，明确标题、数值、标签和辅助说明的字号层级。
- 根据用户增强对比度的反馈，输入控件边框使用 `#91a3bb`，与卡片及输入区形成清晰边界；主要数值使用白色，指标卡单独提亮，参数页签底部略深。当前模式和设备选中行使用更明确的蓝底及亮蓝标记，选中行悬停仍保留选中色。
- 图表使用相同的颜色变量，系统表单控件、滚动条和标题栏进入深色模式。

## 依赖与验证

基于现有 React/CSS 和 Tauri 配置实现，使用本机字体及 SVG 图形。检查 1520 × 960 和 1000 × 720 下的实际界面、硬件列表滚动及分页、输入焦点与校核状态。完成对比度检查、前端构建与交互回归，并打包桌面程序；保留此前的窗口关闭和列表裁切修复。

## 实施与界面验证（2026-09-26）

- 导航：三处入口及二维／三维切换统一使用蓝灰选中状态，型号与标题采用灰白色。
- 布局：保留三列工作台和硬件列表独立滚动。卡片、输入区、列表表头采用不同亮度；设备详情支持键盘聚焦滚动。
- 文字：正文与辅助说明同步提亮；中文型号换行、参数单位、警告说明和分页按钮在实际截图中均可辨识。
- 视觉：人工核对 1520 × 960 的真实内置硬件工作台、资料库，1000 × 720 的窄窗口，以及三维示意、设备弹窗。窄窗口无页面水平溢出，长参数通过纵向滚动访问。
- 自动检查：6 项前端单元测试、13 项连接真实 Rust API 的交互测试通过；资料库和选择弹窗滚动覆盖 1520 × 960、1280 × 800、1000 × 720。初始工作台、设备弹窗及真实方案工作台、资料库通过 Axe WCAG 2 A/AA 检查。
- 构建：TypeScript、Vite 生产构建和 Windows Release／NSIS 安装包成功。程序位于 `target/release/visionselect-desktop.exe`，安装包位于 `target/release/bundle/nsis/VisionSelect_3.0.0_x64-setup.exe`。
- 桌面回归：本轮调色期间通过空白方案关闭、保存后关闭、未保存时返回再确认关闭三种原生窗口测试；后续对比度调整仅修改 CSS，不涉及关闭逻辑。UTF-8 和代码格式检查通过。

增强对比度后，重新通过初始工作台、已选设备弹窗以及真实方案工作台、资料库的 Axe 检查，并重新核对大窗口与窄窗口截图。卡片正文对比度约 7.7:1，输入框边界与周围卡片的对比度约 3.5:1；禁用状态保留弱化显示。

实际预览位于 `.codex_tmp/rust-ui/石墨灰工作台.png`、`石墨灰硬件资料库.png` 和 `石墨灰窄窗口.png`。预览使用独立数据库中的内置硬件快照，校核结果来自 Rust 核心；原始硬件资料未修改。
