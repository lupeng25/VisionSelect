# 国产镜头补库记录

## 目标与范围

本次按原厂公开的具体型号补充灿锐光学、慕藤光和桂林桂光仪器有限公司的镜头资料。桂光只收录官网“单筒视频显微系统”下的独立镜头型号，不把体视显微镜整机或第三方描述当作镜头导入。

内置资料与用户产品库仍分别保存。旧用户库通过一次性增量批次加入新型号，遇到同一厂家、同一型号的既有记录时跳过，避免覆盖用户导入与历史方案快照。

## 来源与处理

| 厂家 | 官方来源 | 原始记录 | 入库型号 | 处理方式 |
| --- | --- | ---: | ---: | --- |
| 灿锐光学 | [Canrill 官方英文站](https://www.canrilloptics.com/)的 21 个型号规格表 | 585 | 584 | 同名型号去重，保留全部原始行与来源页 |
| 慕藤光 | [镜头在线选型](https://www.mvotem.com/list_99/)的 `ID=99` 接口 | 260 | 214 | 排除 5 条型号字段空记录（其中 1 条是已有型号重复）、34 条重复记录，以及 7 条棱镜、转塔、对焦传感器或泛称产品 |
| 桂林桂光仪器有限公司 | [固定倍率](https://www.cglg.net/cn/fixed-magnification-series.html)、[手动变焦](https://www.cglg.net/cn/zoom-lens-series.html)、[电动变焦](https://www.cglg.net/cn/motorized-zoom-lens-series.html)三个官网目录 | 7 | 7 | 卧式系列产品页中的 4 个 DXT 型号，加上 TL-60000、TL-68、TL-62；不收录显微镜整机 |

可审计原始资料分别保存在 `resources/data/canrill_lenses_source.json` 与 `resources/data/mvotem_lenses_source.json`。桂光的逐型号官网摘录与来源页保存在 `resources/data/guiguang_lenses_source.json`；三家的规范化型号各保存在对应 CSV 中。慕藤光中文官网名称为“慕藤光”，与现有光源资料的厂家写法一致。

慕藤光在线表的倍率范围、工作距离范围和组合配置保持原文；仅把单一、明确的数值写入计算字段。原厂“靶面”中的 `φ` 值写为适配传感器最大对角线，不冒充实测像圈。变倍镜头、显微物镜、管镜和组合光学组件不会按定焦镜头的近轴公式自动推算视场。参数为空代表原厂选型表未给出，不能解释为零。

用户提供的 59 页《镜头产品综合总册》是扫描版。本次用它抽查类别及漏项，但以在线选型接口作为当前入库边界。例如总册中的 `MF200-C-44-M58` 未出现在在线选型响应中，未据此推定它仍是当前可选型号。因此“214”表示在线接口中可唯一识别且属于镜头或光学组件的型号数量，并不代表厂家所有历史、定制或纸本型号。

桂光官网连接间歇超时，目录及可读取的产品页通过只读网页文本抓取核对；保存的 `source_url` 均指向原厂页面。DXT 系列的景深仅在官网指定的 1/2 英寸 CCD、320 TV 线条件下成立，因此只保存原文条件值，不作为通用景深参与校核。官网 TV 失真表中的字符不清晰，也未转为数值。TL-60000、TL-68 的详情页超时，仅收录官网目录可核实的型号与镜头类型，其他规格留空。桂光其他未公开或定制型号不在本次可核实范围内。

## 依赖、验证与退出条件

资料同步不依赖登录凭据；源码中只保存公开产品字段、型号与原厂链接，不保存浏览器会话信息。验证包括：原始记录与入库数量、型号唯一性、关键型号字段、旧库增量插入不覆盖用户记录、Rust 工作区测试、前端构建与测试、真实 Rust API 端到端测试，以及中文文本编码检查。

本批次的退出条件是三家当前可核实的公开在线型号可检索、可筛选、可追溯，且回归测试通过。对于官网未列出的历史或定制型号，不声称已经收全；若后续取得原厂完整型号表，再按独立批次补入。

## 验证结果

全新数据库加载 1,809 款镜头、共 5,649 条内置硬件资料。`cargo test --workspace`、`npm run build`、`npm test`、44 项 `npm run test:e2e`、Rust 格式检查和文本编码检查均通过。新镜头通过真实 Rust API 验证资料库导航、搜索、选择和详情；1520 × 960 与 1000 × 720 两种窗口宽度下，文字可读，详情面板无水平溢出，筛选区、列表和详情区布局正常。
