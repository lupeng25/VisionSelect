# 2D 选型计算页面

## 目标、范围与依赖

新增独立导航“2D 选型计算”，用于选设备前的参数推算。四组工具分别覆盖视场与分辨率、镜头与工作距离、运动与曝光、传输与存储。支持手动输入、读取当前方案、保留独立计算草稿，以及将明确列出的参数应用到二维工作台。

计算统一放在 `vision-core`，通过现有 Store 请求分发同时供 Tauri 和开发 API 使用；沿用当前石墨灰高对比度界面和原始硬件资料。不新增外部依赖，不更改设备参数、硬件原始文件和现有方案存储格式。

## 计算规则

- 分辨率：所需视场为工件尺寸加两侧余量；最低横纵像素数分别向上取整。所选分辨率按原纵横比覆盖所需视场，不能用总像素数代替两轴要求。物方像素当量不等于系统测量精度。
- 镜头：传感器尺寸由有效像素数和像元尺寸得到；定焦使用与工作台一致的近轴估算。求焦距和远心倍率取两轴允许值的较小者，求工作距离取两轴要求的较大者。固定倍率视场按传感器尺寸除以倍率计算。近轴倍率超过 0.1 时突出提示精度限制。
- 运动：匀速拖影为速度乘曝光时间再除以物方像素尺寸；曝光上限同时受拖影要求和目标帧周期约束。静止时不产生运动限制；尚未计入相机读出和触发延迟。
- 传输：复用已有像素格式与行内字节对齐规则。明确区分 Mono12 的 16 位容器与 Mono12p 打包格式。使用十进制 MB、GB，存储按完整帧向上取整，不包含压缩、协议和文件元数据。

光学公式及适用范围参考 [Edmund Optics 成像基础](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/understanding-focal-length-and-field-of-view/)；运动曝光和传输格式参考 Basler 官方文档中的 [图像质量](https://docs.baslerweb.com/optimizing-image-quality) 与 [像素格式](https://docs.baslerweb.com/pixel-format)。公式推算用于前期选型，不能替代镜头数据表和现场验证。

## 使用方式

从左侧“2D 选型计算”进入，四组参数分别保留。首次提供可编辑的示例值，“读取当前方案”带入已知设备和现场参数；缺失的规格保留手动值并显示说明。运动计算优先读取当前安装条件下的成像像素当量，两轴不同时取较小值。

选择镜头计算目标可求视场、焦距、工作距离或远心倍率。分辨率工具中的“用这个视场继续算镜头”会带入所需视场及相机参数。计算公式可在结果下方展开。

“应用参数”仅写入按钮旁列出的二维参数，然后返回工作台；所选设备、实测视场标记、参考快照和三维参数保留。远心倍率需在资料库选择镜头，不会作为硬件规格直接写入。空值、不适用模型或超出工作台可用范围的参数禁止应用，避免继续使用旧结果。

本页草稿使用独立本地存储，不混入工程方案文件；切换页面、重新打开应用后会恢复。微小非零结果采用科学计数法，避免四舍五入显示为零。
