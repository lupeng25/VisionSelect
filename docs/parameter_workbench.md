# 视觉参数工作台使用与实现说明

## 当前实现

侧栏“参数校算”现已进入六任务工作台。首次打开不自动填写硬件参数；“载入示例”只加载当前任务的示例，并在公共相机参数全部为空时补充示例相机。已有输入会随任务切换保留。

| 任务 | 已实现的求解方式 | 关键结果 |
| --- | --- | --- |
| 视场与焦距 | 求焦距、求视场、求距离；矩形视场、工件加单边余量、圆形目标 | 双向覆盖、实际像素当量、常见焦距比较与示意图 |
| 分辨率与采样 | 求需求分辨率、已有相机的实际采样、局部实测标定 | X/Y 分辨率、像素当量、特征覆盖像素、标定方向和区域 |
| 方案校核 | 普通/远心镜头；模型估算或实测视场 | 目标、当前值、逐项状态和可查看的依据 |
| 远心倍率 | 求视场、求倍率上限、求可行倍率区间 | 采样下限与视场上限、无解原因、常见倍率比较 |
| 运动与曝光 | 求最大曝光、预计拖影、允许速度 | 使用手动或方案校核 X/Y 像素当量计算 |
| 带宽与存储 | 单相机或共享链路多相机、可选 ROI、传输及主机保存格式 | 单帧载荷、吞吐、链路利用率、GB 与 GiB 存储容量 |

## 如何使用

### 从相机和视场确定镜头

1. 在公共相机区填写有效分辨率与像元，或从产品库导入。
2. 进入“视场与焦距”，选择求焦距。
3. 输入目标视场 X/Y 和距离；也可以选择工件尺寸加余量、或圆形目标。
4. 选择合适的计算模型。初始使用近轴粗算，结果属于估算。
5. 查看理论焦距和下方常见焦距表。表中覆盖、采样分别判定，不能只看视场够不够。
6. 点选比较行可切换为该焦距的视场校核；使用“按当前条件找镜头”查看目录候选。
7. 使用“用于方案校核”带入计算值。此操作清除上一镜头的像圈、距离范围、景深等规格，避免沿用不相关硬件数据；需要时在方案校核中重新导入具体镜头。

### 从检测要求确定相机分辨率

1. 进入“分辨率与采样”，选择“所需分辨率”。
2. 填写视场 X/Y、最小特征及每特征像素数。
3. 如果使用测量误差预算，启用相应选项并填写误差与预算像素数；也允许只填这组预算、将特征参数留空。
4. 同时提供两种预算时采用较严格的像素当量，不会自动放宽极小目标。
5. 分别查看 X/Y 最低分辨率。使用“用于方案校核”时只带入需求，不把最低分辨率当作已购相机规格。

### 检查已有设备

1. 在公共区导入或填写相机；在“方案校核”中导入镜头及安装条件。
2. 输入需求视场、像素当量上限和帧率。传输检查需明确像素格式与有效链路容量。
3. 有实测视场时选择“使用实测视场”，填写 X/Y 实测值。
4. 安装范围、景深、远心度和运动条件在可展开区域中填写。展开与收起只改变显示，不改变已填写条件。
5. 选中结果行查看计算依据；“待补参数”不计为通过。最大帧率为 0 或缺失时按未知处理。
6. 改变共享相机分辨率或像元后，原实测视场会失效并清空，需要重新记录；只换显示单位不会使实测值失效。

## 单位、模型与状态

- 空白表示未填写。无效输入在结果区提示，不弹出连续报错窗口，也不保留旧的正常结果。
- 支持常用长度、像元、速度与曝光单位切换。输入转换为 mm、μm、mm/s、μs 等基准单位后计算。
- 近轴模型使用 `FOV ≈ S × 距离 / f`；薄透镜模型使用 `FOV = S × (物距 − f) / f`。薄透镜物距从物方主平面起算，不能直接当作镜头前端工作距离。
- 原二维选型和候选计算的薄透镜公式保持原义。新工作台默认近轴模型，所以同一距离数字可能得到不同估算；对比时须统一模型和基准。
- 远心视场由倍率决定；工作距离用于安装规格校核。
- 景深只有在用户确认规格适用于当前倍率与光圈后，才判定覆盖情况。缺少适用条件时保留待补状态。
- 结果状态分为满足、不满足、待补参数、不适用、输入无效。普通计算显示“已计算”，不直接等同方案通过。
- 速度为零时显示无运动拖影约束，不输出无穷大曝光。

采样满足不保证光学分辨能力或最终测量精度；此版本尚无完整的 MTF、镜头曲线插值和系统误差预算模型。短距离、畸变、光照及快门读出条件仍需独立验证。

## 传输格式与旧数据

传输模块明确区分 Mono8、Mono10/12 的 16 位容器、Mono10p/12p 打包格式、Mono16、部分 Bayer 格式和 RGB8。每行末尾补足字节；设备额外行对齐、文件头及压缩不在当前载荷模型中。

例如 2000 × 1000 像素，Mono12 为 4 MB/帧，Mono12p 为 3 MB/帧。主机保存为 RGB8 时，保存容量单独计算，不反向改变相机传输载荷。

旧产品库的相机字段仍保留兼容结构。明确的格式名称按实际存储位数计算；只有 Mono/Color 类型及位深的目录记录，原选型入口保留估算并增加“格式未确认”提示。工作台导入这类记录时不自动选择传输格式，要求用户确认，未修改或批量重写用户目录。

MB、GB 分别为 10⁶、10⁹ byte；GiB 为 2³⁰ byte。旧存储计算混用 1000/1024 的问题已修复。

## 产品库、保存与对照

- 相机、镜头均支持搜索和分页导入，缺失规格保持空白。
- 工作台的“匹配镜头”使用最多 500 项目录预筛候选，再按当前模型检查视场、采样、安装与像圈等条件。它不是全库穷举；页面明确显示预筛范围和缺项，不承诺最终精度。
- 产品库导入的数据标明制造商和型号。后续手动修改时显示修改标记。
- A/B 保存独立的输入、单位、选项、来源和结果快照。后续编辑当前任务不会改动已存快照；再次点击保存 A 或 B 才替换对应槽位。
- 复制功能导出当前任务的参数、计算值、状态与依据，可粘贴到记录或报告中。
- 工作台使用稳定字段名保存状态，版本号为 1。切换语言、改变密度、离开页面和关闭后重开均保留状态；不再按子控件顺序恢复本页面。

## 代码划分

| 模块 | 职责 |
| --- | --- |
| `src/core/SamplingPolicy.*` | 需求、预筛和选择共用的采样策略 |
| `src/core/PixelFormat.*` | 明确像素格式的存储布局和行字节计算 |
| `src/selection/CalculationStatus.h` | 共用状态与上限比较 |
| `src/selection/ParameterCalculator.*` | 六任务的独立计算输入、输出和逐项校核 |
| `src/ui/ParameterNumberField.*` | 可空数值字段及单位转换 |
| `src/ui/ParameterWorkspaceState.h` | 稳定键的状态与快照结构 |
| `src/ui/FovDiagram.*` | 当前视场与需求区域示意 |
| `src/ui/ParameterCatalogDialog.*` | 产品查询、分页和候选复核 |
| `src/ui/pages/PureCalculation*.cpp` | 工作台容器、任务面板、结果呈现和目录接入 |

`CalculationAssistant::estimatePure()` 仍供原有调用方使用，已修复实际采样与最大帧率判断，并增加有效状态。工作台使用独立计算接口，避免六项任务继续依赖一份聚合长表单。

## 验证项目

自动测试覆盖原审查案例、双模型三方向求解、双轴覆盖、严格采样目标、局部标定、远心区间冲突、零速度、ROI 与像素打包、主机保存格式、未知规格、单位转换、失效实测数据、独立快照及跨语言/重启状态恢复。

界面检查使用真实 Qt Widgets 渲染图，覆盖 1440 × 900、1024 × 740、中英文和舒适/紧凑密度；检查任务导航、输入与结果的滚动可达性、文字换行和横向溢出。150% 缩放单独运行同一组界面验收。

调研依据与修复前的复核记录见 [视觉工具对标](vision_tools_benchmark.md)；原交互设计见 [工作台重设计方案](parameter_workbench_proposal.md)。
