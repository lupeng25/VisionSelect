# 界面层次与过渡优化

## 目标与范围

保留现有布局和石墨、瓷白、暖砂、雾青四套皮肤，减少区域交界的生硬感，让导航、卡片、表格、详情和弹窗的视觉衔接更自然。正文、输入框、选中项以及校核状态继续保持清晰可辨。

## 实施范围与依赖

- 在现有主题变量上区分结构边界、内部接缝与可操作控件；以柔和背景、细描边和分层阴影体现区域关系，统一圆角。
- 侧栏边缘与主背景自然衔接，弱化顶栏和状态栏的横向分隔；减少卡片内部操作条、表头及详情区域的色块跳变。
- 使用原生 CSS 提供页面、参数分组、弹窗和悬停反馈的短时过渡。不引入动画依赖，不对数值、尺寸或表格滚动做补间。
- 复用现有 React 状态，切换页签只为对应内容区域提供进入动效；减少动态效果偏好关闭动画与过渡。
- 不修改 Rust 算法、接口、硬件资料或持久化格式。

## 验证与退出条件

复核四套皮肤在主要页面和 1000 × 720 窄窗口的导航、布局、文字、状态与对比度；检查动画期间及结束后浮层定位、列表滚动、焦点恢复和快速切换。连接真实 Rust API 运行现有交互回归，补查减少动态效果；通过常规检查、实际桌面与打包，保留现有工作内容后交付。

## 完成与验收

2026-09-26 已完成。四套皮肤共用结构描边、柔和接缝、背景过渡层和指标底色变量，输入控件继续使用原有清晰边界。卡片采用 15 像素圆角及双层柔影，主要弹窗采用 18 像素圆角；侧栏、顶栏和状态栏更自然地融入主背景，表格与详情的分隔线同步减轻。

页面与参数分组进入使用 180 毫秒动效，表面颜色和阴影使用 240 毫秒过渡。页面和弹窗没有设置 transform，确保其中的固定筛选浮层始终按视口定位；参数分组的微量位移不作用于计算数值或控件尺寸。减少动态效果时全部动画和过渡关闭。

- 导航：四个页面、参数页签、设备弹窗及更多筛选正常切换；当前输入、设备、筛选与主题偏好均保持。键盘关闭后焦点回到入口。
- 布局：1520 × 960、1280 × 800、1000 × 720 的既有滚动和分页回归通过；窄窗口皮肤面板完整可用，详情与加入按钮没有新增裁切。
- 文字：输入框、表格选中项、校核状态保留清楚的对比。四套皮肤主要页面与弹窗在动效完成后的 WCAG 2 A/AA 自动检查未报告违规；检查会等待有限动画结束，不把瞬间淡入透明度当作最终配色。
- 视觉：人工核对四套工作台，以及资料库、计算页和窄窗口截图。14 张实际界面截图位于 `.codex_tmp/rust-ui/柔和层次-*.png`；动态演示为同目录的 `柔和层次-动态演示.webm`，使用真实内置硬件与独立示例草稿录制，未出现页面错误。

验证结果：Rust 43 项、前端单元 9 项通过；既有交互 24 项通过，主题与减少动态效果 9 项通过。Rust 格式、Prettier、UTF-8、TypeScript、Vite 与 Windows Release/NSIS 构建均通过。实际桌面再次验证四套切换、原生标题栏同步、完整退出重开后的偏好恢复与正常关闭。
