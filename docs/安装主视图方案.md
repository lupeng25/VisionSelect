# 安装主视图方案

## 目标与范围

在方案工作台成像区增加“成像平面 / 安装主视图”切换。主视图按照用户参考图采用正投影表达：相机、镜头、光源和被测物沿中心线布置，左侧设备标签，右侧两段尺寸线。三维采样继续使用原有扫描图。

## 数据与呈现

- 展示当前方案的硬件型号。镜头前端到工件的距离使用现有“镜头工作距离”，光源距离和两段安装公差可在图下填写，随方案保存、导入、导出和参考对比。
- Rust 参数增加可选的 `light_distance`、`distance_tolerance`、`light_distance_tolerance`，缺省均为空；旧方案及浏览器草稿保持兼容。零公差有效，非法数值阻止保存。安装公差只作为标注，不改变光学校核，也不等同于景深或厂家允许范围。
- 按光源类型自动展示环形、条形侧向、同轴、背光或穹顶布置。下拉框提供临时预览，不改变硬件或保存状态；切换视图本身也不修改方案。
- 默认光源距离和公差显示“待确认”，不套用参考图的示例值。正向光源距离从下出光面量至工件上表面，穹顶采用开口面，背光从上发光面量至工件下表面，侧向光源标注垂直安装高度。
- 目录缺少完整机械外形，图形明确为非等比例的典型安装示意，未进行支架和机械干涉校核。已知距离调整正向光源的示意位置，但图内间距受排版限制，不可从图上量取真实尺寸。
- SVG 使用现有主题变量，四套皮肤共享布置。窄窗口完整缩放显示两段尺寸线，设备长型号省略并提供完整标题提示。空硬件使用虚线占位。
- 本功能未改写硬件原始资料；工作区其他硬件资料变更保留。

## 验证与完成条件

通过真实 Rust API 验证参数联动和保存恢复、旧方案兼容、空值和非法值、视图切换和三维模式隔离；检查四套主题、窄窗口、键盘操作和文字适配。完成常规检查与桌面构建。

## 审查问题修复（2026-09-28）

- 线扫镜头的面阵适用性改为“待确认”，不再仅凭类别判定冲突。未填写实测视场时仍不套用近轴估算；启用实测后保留宽高，继续校核采样和覆盖，不掩盖实际的覆盖不足。
- 安装距离与公差按已存数值的有效精度标注，例如 `0.001 mm` 不再显示为零。零公差和未知公差仍分别显示 `± 0` 与不带公差的尺寸。
- 回归覆盖实测开关、微小公差保存与重开；窄窗口下检查明暗皮肤及尺寸文字，光源距离文字放在内侧尺寸线左侧，避免增加小数位后跨越外侧尺寸线。
