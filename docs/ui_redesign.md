# 界面重构说明

## 设计方向

以成熟的工程工作台为目标：石墨黑导航与银灰工作区形成层次，低饱和蓝紫色集中用于当前导航、选中项与主要操作。减少全屏边框和实色按钮，统一线形图标、圆角、标题、辅助文字和数据间距。

## 页面调整

- 需求建模：移除重复的大纲栏，将尺寸、精度、节拍、光学偏好和备注组织成编号卡片。右侧展示随输入变化的工件与视场示意、核心指标及工程提示；底部固定“生成选型方案”操作。
- 参数校算：突出实际视场、物方像素和带宽利用率，完整计算依据保留在下方可滚动详情中。
- 候选计算：统一表格行高、表头、按钮与标题样式，减少网格线干扰。
- 方案评审：匹配度数值与解释文字分层，保留兼容状态、风险、产品组合及详细校核信息。
- 产品库：调整型号和参数的默认列宽；原有列宽设置仍优先恢复，筛选、分页和数据操作保持原有功能。
- 3D 相机：精简统计说明，将筛选面板改为局部滚动，避免高级筛选或小窗口撑大整个应用。

## 实现位置

- `resources/styles/base.qss`：字体、密度与通用控件结构。
- `resources/styles/light.qss`：普通主题的颜色、层次与组件状态。
- `src/ui/UiThemeManager.cpp`：统一样式、调色板及高对比模式。
- `src/ui/UiHelpers.cpp`：线形图标、通用卡片和表格行为。
- `src/ui/pages/`：需求页、结果页、校算页、产品库及 3D 页布局。

新需求页分隔器使用独立的设置键，避免旧三栏尺寸影响双栏布局；不删除用户旧设置。

## 验证方法

使用真实的 Windows Qt Widgets 渲染检查页面，不用网页模拟桌面界面。UI 回归覆盖导航、输入和备注保留、摘要显隐、异步计算完成、小窗口尺寸及语言切换；原有算法、导出和授权测试继续保留。

可通过以下方式输出页面截图。请先构建，并将 Qt 运行库目录加入 `PATH`。

```powershell
$env:VISIONSELECT_UI_CAPTURE_DIR = "$PWD\.codex_tmp\ui-review"
.\build\windows-msvc2022\bin\VisionSelectUiTests.exe -o .codex_tmp\ui-review-tests.log,txt
```

截图用于逐页检查标题、导航、布局、表格和文字适配。测试窗口采用不显示到桌面的方式渲染，因此这项验证不等同于真人操作窗口拖拽、系统贴靠或切换系统高对比模式；这些系统级交互仍可在实际部署环境补充验收。
