# 产品计算助手与推荐结果修复说明

对应审查：[产品计算助手与推荐结果审查](calculation_results_review.md)。

## 判定和结果一致性

- 新增共用的逐项校核：FOV、物方采样、像圈/靶面、接口、工作距离、景深、帧率、带宽、快门和传输像素格式。助手与推荐引擎保留同一套状态，区分满足、待确认、不满足及不适用。
- 候选先按校核状态排序，再按同一状态内的得分排序。已知像圈、安装或景深条件失败不能被其他加分抵消；工作距离等必要资料缺失不再显示为满足。
- 页面状态改为“不满足”“待确认”“初筛通过”。逐项失败和待确认项排在通用风险前面；百分比保留为本批候选的相对排序参考。
- 主窗口将当次需求与结果存放在同一个快照中。助手导航、需求编辑和语言切换不再覆盖该快照。PDF 和 BOM 都使用该次快照；需求变化后返回结果页会提示旧结果仍对应上次需求，并提供重新计算入口。

## 候选覆盖与计算开销

- 删除引擎在组合检查前将相机截为 96 台的逻辑，保留传入相机的组合评估机会。目录服务已有的检索限额仍然保留；修复不表示穷举了整个产品库。
- 相机的带宽、帧率和传输格式只在每台相机上计算一次；光源检索按全局快门、远心和同轴照明三项属性复用八种组合，减少目录扩展后的重复计算。
- 助手显示全部已检索的相机候选，不再只给用户 12 台可选相机。初次进入时，如已有相同需求的推荐结果，则优先使用其中的相机；后续刷新按厂家和型号保留用户选择。

## 页面与交互

- 产品计算助手默认收起相机选择区，以镜头候选为主表。选中相机始终显示在上方，镜头状态和失败/待确认项显示在表格及下方摘要中。
- 鼠标、方向键和恢复选中项使用同一个相机联动入口。每个镜头都能打开自己的校核详情，不再固定显示“首选镜头”的说明。
- 推荐页默认收起前三方案卡片及完整详情；表格优先显示型号、FOV、采样、状态和风险。倍率、焦距、工作距离及景深保留在校核详情中。
- 详情先显示当前组合、安装与成像参数、逐项校核及风险，再显示公式和其他估算。型号可在选中项摘要和详情中读取、复制。
- 数值显示与排序值分离；匹配度、采样、分辨率、FOV 等按数值排序，未知值排在已知值后面。
- “接口容量”和“接口剩余量”分开显示，剩余量为容量减去估算占用，负值表示不足。

## 回归范围

- 算法：像圈失败在助手和引擎中的一致性；可行镜头优先；工作距离和景深缺失的待确认状态；景深不足的失败状态；第 97 台相机为唯一兼容项的边界情况。
- 导航与状态：生成旧结果、编辑需求、进入助手、返回结果、切换语言后，快照继续保持原需求；过期提示可见。
- 交互：方向键切换相机、重排列表后保留产品身份、选择不同镜头查看对应详情。
- 排序与文字：100、97、9 的百分比升降序；待确认状态；2400 MB/s 容量和 675 MB/s 占用对应 1725 MB/s 剩余量。
- 布局：主表占页面高度超过 60%；检查相机选择区、校核详情、旧结果提示、中英文和缩放适配。
