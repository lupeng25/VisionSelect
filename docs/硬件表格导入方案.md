# Excel / CSV 硬件导入优化方案

## 目标和范围

提供“选文件与工作表 → 对应字段 → 检查差异 → 确认导入”的独立流程。支持 Excel XLSX/XLS 与 CSV 参数表，保留现有 JSON 和旧数据库导入入口。仅修改用户资料库，不改内置原始文件与方案快照。

## 实施与依赖

1. Rust 使用 calamine 读取工作簿；CSV 延用 csv 解析器。支持选择工作表和表头行，返回样例、中文字段与自动对应建议。
2. 前端提供字段对应选择、忽略列及明确的数值单位提示；CSV 支持 UTF-8 与 GB18030。未识别列不擅自推断，单位不自动换算。
3. Rust 校验必填值、数值、同文件重复型号，返回原始行号与错误原因。默认整批阻止错误数据写入，可明确选择跳过错误行后重新预览。
4. 同型号支持跳过、仅补空值和覆盖非空字段；默认仅补空值，空单元格不清除已有规格。逐条提供参数前后差异，预览令牌绑定实际待写入内容。
5. 继续事务写入与导入前备份。旧 API 保持兼容，表格流程使用独立检查与预览操作。

## 验证与退出条件

核心测试覆盖 XLSX 多工作表、中文表头、字段对应、非法数值、重复型号、三种合并策略、备份和快照保持。端到端连接真实 Rust API，验证文件选择、字段对应、错误行及差异确认、窄窗口与键盘操作。完成构建、常规检查、视觉检查和桌面打包后交付。

## 使用方式

1. 在硬件资料库点击“导入硬件”，先进入导入面板。可选择目标分类、下载 CSV 表头模板，或拖入文件；只有点击面板内“选择文件”才打开系统文件选择器。选择 `.xlsx`、`.xls` 或 `.csv` 后进入字段对应流程；JSON 与旧数据库继续使用原有合并预览。
2. 选择硬件分类、工作表和实际表头行。CSV 可切换 UTF-8 / GB18030 编码及逗号、分号、制表符分隔。
3. 检查每列的目标字段。型号、厂家必须对应，目标字段不能重复；未对应列会被忽略。数值单元格使用纯数值，按下拉框内的单位准备；不确定的单位不自动换算。可下载当前分类的 CSV 表头模板。
4. 选择同型号处理方式并检查差异。“仅补充空参数”保留已有非空值；“覆盖表中提供的参数”只覆盖对应的非空单元格，未提供字段保留。数值 0 属于已有值，不作为空值自动补充。
5. 有错误时默认禁止整批写入。返回修正文件，或明确勾选跳过错误行后重新检查。同文件重复型号的后续记录按错误行处理。
6. 展开参数变化核对旧值和新值，再确认写入；自动备份路径在完成提示中显示。无变化时不会重复写库。

单文件上限 32 MB、十万条数据、200 列；预览与错误详情分别最多显示前 100 条，总数覆盖完整文件。Excel 公式使用已保存的缓存结果，不执行计算。用户应在原工作簿完成重算后保存再导入。
