## 结论与边界

原始资料**不能整体判定为正确**。已经用厂商官网直接确认：7 款 LMI Gocator 2300 的标准激光规格与底稿记录冲突；5 款大恒相机把官网“信噪比”数值写入“动态范围”字段；1 款视清远心镜头的远心度与官方规格书不符。另有带宽口径、零值含义和来源可追溯性问题，尚不能据此断言其余型号均错误。

本次完成全量结构与异常扫描，并按风险抽查厂商型号及官方原文。**没有逐一完成 4,844 款设备的每个字段认证，也没有实物验证。** 下文严格区分“官网证实不一致”“官网证实相符”“待核”。

## 官网证实不一致

### 1. LMI Gocator 2300 激光类型与波长

内置的 `Gocator 2320、2330、2340、2350、2370、2375、2380` 均写为“蓝色激光、405 nm”。[LMI 官方 Gocator 2300 规格表](https://am.lmi3d.com/manuals/gopxl/gopxl-1.1/LMILaserLineProfiler/Content/Specs/G2/Gocator2300Series/Gocator2300Series.htm?TocPath=Specifications%7CSensors%7CGocator+2300+Series%7C_____0)明确说明：除非另有标注，系列型号的波长为 **660 nm**；道路应用版本 `2375` 又单独列出 **808 nm 近红外**。官方还说明光学型号和激光等级可定制。因此这 7 条统一写死 405 nm **与官方标准配置不符**，但最终订货波长仍须结合具体料号或激光等级确定。`Gocator 2390` 也写了 405 nm，但官方当前规格表未列出此型号；库内本就标为“未能官网确认”，应继续维持待核，而不能套用其他七款的结论。

首次核对时，运行时校正仅处理七款的几何字段，激光颜色和波长仍直接显示旧值；现已增加受来源与旧值约束的光源校正。最终订货仍需核对具体激光变体。

### 3. 视清远心镜头远心度及已公开参数缺失

`APO-DTJCA25M-2C-110-G` 主表的 `telecentricity_deg=0.1`，而[视清官方单型号规格书](https://www.coolens.cn/upfile/2025070753032153.pdf)明确给出**物方远心度最大 0.06°**；工作距离 110 mm、放大倍率 2×、支持靶面直径 20 mm、畸变最大 0.04% 则与主表相符。官方还给出理论景深 0.17–0.44 mm、像方最佳 F/# 8.4–22，主表的 `dof_mm` 和 `f_number` 均为 0。这两个 0 应理解为**未录入**，不能当作官方宣称景深或光圈为零。视清主表 752 条中，远心度填 0.1° 的有 374 条；目前仅此型号已由独立规格书确认差异，不能外推为 374 条均错误。

### 4. 既有 Gocator 2300 几何记录的语义问题

七款主 JSON 的 `referenceDistanceMm` 实际填的是官方 `Clearance Distance (CD)`，`xFovReferenceMm` 是近、远端 FOV 的算术中点；[LMI 官方表](https://am.lmi3d.com/manuals/gopxl/gopxl-1.1/LMILaserLineProfiler/Content/Specs/G2/Gocator2300Series/Gocator2300Series.htm?TocPath=Specifications%7CSensors%7CGocator+2300+Series%7C_____0)只给 CD、MR 和近远 FOV，不保证中点对应某个可称为“参考距离”的截面。此前的运行时修复会在读取内置资料时为七款补出 `workingDistanceMinMm=CD`、`workingDistanceMaxMm=CD+MR`，并撤销无依据的参考截面均值；原始 JSON 按项目约束保留。这是**原始字段语义仍不正确，但当前运行时已有局部校正**的情况，见[三维修复方案与验证](三维修复方案与验证.md)。

## 待核与来源冲突

1. **相机带宽口径。** 在“满分辨率、目录最大帧率、Mono8 无压缩、`bandwidth_mbps` 实际按 UI 的 MB/s 解释”的保守条件下，228/1,393 条的最低纯图像载荷超过目录带宽的 105%。例如 `MARS-251-1938X2C-NF` 至少约 **4,826 MB/s**，目录为 **1,200 MB/s**；[大恒规格书](https://www.daheng-imaging.com/uploadfile/2025/0310/20250310103759850.pdf)同时确认满幅 1937.98 fps 和 **CXP-12 × 4**。这强烈表明目录值可能是单通道额度或通用预设，不能作为整机容量。另一个 `MV-CH210-90Q2M-M58S-NF` 的最低载荷约 **11,346 MB/s**，目录值 **1,000 MB/s**。228 条是**待核候选数，不是 228 条官网证实错误**：ROI、压缩、位深、并行链路和带宽定义都需核实。代码中此字段名含 `mbps`，界面却标 `MB/s`，应明确单位和 `per-link/aggregate` 口径；现有 Rust 校核仅在 `bandwidth_source=specified` 时采用目录容量。
2. **LMI 型号版本。** `Gocator 2390` 在本次访问的 2300 官方表中不存在，也未找到可直接核对的厂商规格；因此型号和数值继续标待核，不推断其从未生产。LMI 其他系列也有大量 405 nm 记录，但部分如 2500 系列确有蓝光配置，不能把 2300 结论外推。
3. **深视 SR5540 外形尺寸。** 库内 `608×98.5×62 mm` 与[厂家安装图](https://www.cnsszn.com/upload/download/SR5540%E5%AE%89%E8%A3%85%E7%A4%BA%E6%84%8F%E5%9B%BE.pdf)的总长 608 mm 一致，[厂家技术规格书](https://www.cnsszn.com/file/SR5540.pdf)却写 610 mm。同厂两份资料不一致，应按硬件修订版或厂家答复确认，不能单凭其中一份判库内错误。
4. **来源可追溯性。** 相机主表无 URL；视清主表的多数型号仅能回到系列采集页；3D 的海康记录大量共用列表接口，`SR5540` 原 `sourceUrl` 页面未直接呈现完整规格。本次找到的深视原厂 PDF 可用作更精确的核对依据。缺少逐型号证据时只能标“未核实”，不能因记录存在就认定正确。
5. **其他光源品牌。** 康视达抽查的颜色和波段相符；OPT 与慕藤光的型号参数尚未获得足够可比对的逐型号官方明细，本次没有给它们下全库正确结论。`wavelength_nm=0` 需拆为“未公开、白光、多色、不适用”等语义。

## 建议的修复顺序

已隔离证实错误的 LMI 激光字段、大恒 dB 字段和视清远心度，并保留原始文件与可审计的更正层。下一步应把带宽拆为“接口额定总带宽、通道数、位深/ROI 条件、来源”，逐型号复核 228 个候选；为相机、镜头和光源补逐型号官网证据及版本日期，并用空值或明确状态代替未知参数的数值 0。所有订货判断仍应以实际料号的最新厂家规格书为准。
