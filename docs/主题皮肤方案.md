# 主题皮肤与外观切换

## 目标与范围

提供石墨、瓷白、暖砂、雾青四套完整皮肤。保留现有石墨作为默认外观；新增三套明亮主题，适配长时间工程操作。左下角提供带缩略预览的皮肤选择，立即生效并记住偏好。

范围包含导航、工作台、2D 计算、硬件资料库、方案列表、弹窗、校核状态、示意图及 Windows 标题栏。主题切换不重新加载页面，不修改方案、计算输入或硬件资料。

## 实现与依赖

- 使用统一 CSS 颜色变量，为四套主题分别定义背景层级、文字、控件、强调色、状态色和图示颜色，预览卡片复用真实主题变量。
- 使用独立的本地外观偏好键，首次显示界面前恢复；旧版本或无效偏好回退到石墨。存储失败时仍可切换，并明确提示无法记住。
- 沿用原生单选控件及现有模态框，支持方向键、Tab 与 Esc；窄窗口保留带名称的图标入口。
- Tauri 使用本地 SDK 的窗口主题和背景设置接口，仅增加这两项主窗口权限；无数据迁移或新增依赖。

## 验证与退出条件

连接真实 Rust API 验证四套皮肤即时切换、刷新恢复、草稿与筛选条件保留、键盘操作及存储异常；检查主要页面、弹窗、状态颜色和 1000 × 720 窄窗口。运行既有回归、格式、编码和构建检查，核对真实桌面标题栏同步及关闭重开后的选择。四套皮肤文字清晰、无布局裁切、已有功能正常且桌面打包成功后交付。
