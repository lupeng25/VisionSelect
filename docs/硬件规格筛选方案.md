# 硬件资料库规格筛选

## 目标、范围与依赖

扩展资料库页面及工作台选设备弹窗共用的筛选能力。保留型号搜索和厂家筛选，按四类硬件显示真实规格条件；数值范围、枚举条件、搜索和厂家使用交集，先筛选全库，再计算总数和分页。不修改原始资料、硬件快照和用户方案。

依赖现有 `vision-core` 资料读取、Store 请求入口及 React 资料库组件；不增加外部库或数据库迁移。筛选字段及选项由 Rust 根据当前分类资料提供，用户导入新规格后自动更新选项。

## 条件与界面

- 相机：接口、色彩、有效像素总量、最高帧率；更多条件包含快门、传感器规格、镜头接口、横纵像素、像元尺寸和位深。
- 镜头：镜头类型、接口、焦距、远心倍率；更多条件包含像圈、最小及标称工作距离、光圈、同轴照明。
- 光源：形态、颜色、发光宽度与高度；更多条件包含工作模式与波长。多种可选颜色按独立颜色匹配。
- 3D 相机：技术路线、接口、最高扫描频率、Z 量程；更多条件包含采样间隔、重复精度、参考视场、工作距离与编码器支持。

常用条件直接显示，更多条件通过可滚动的浮层展开，避免挤占设备列表。显示当前匹配数量、已选条件、单项移除和全部清空；各分类在当前资料库会话中保留独立条件。列表独立滚动，底部分页和设备加入按钮维持可见。

## 数据规则

数值区间为包含边界的上下限，支持只填一端；相机 MP 由有效横纵像素相乘除以一百万得到。缺失、非数字和表示未公开的非正规格不满足数值条件。枚举可明确选择“未公开”，布尔值的“不支持”和“未公开”严格区分。

选项来自当前分类完整资料，搜索或无结果不会清除已选条件。接口匹配完整条目，不用字符串包含关系混淆 GigE 与 10GigE、C 与 CS。仅在查询层规范大小写、常见名称别名和多值表示，保留原始规格文本。

## 验证与退出条件

1. Rust 测试验证组合条件、区间边界、缺失值、跨分类错误、多值接口、颜色、布尔值、总数和翻页。
2. 连接真实 Rust API，验证四类筛选、清空、分类切换、无结果、非法区间以及筛选后加入方案。
3. 在资料库页面与选择弹窗中检查 1520 × 960、1280 × 800、1000 × 720；验证真实鼠标滚动、浮层关闭、分页可见和对比度。
4. 完成 Rust 和前端检查、桌面构建及独立数据下的预览。筛选准确、列表可操作且原始资料不变后交付。

## 实施与验证结果

2026-09-26 已完成。相机 11 项、镜头 9 项、光源 6 项、3D 相机 10 项，共 36 项分类规格条件。Rust 提供筛选定义、完整分类的选项和公开规格数量；界面复用到资料库与工作台选择弹窗。导入完成后更新选项，筛选条件改变后回到第一页，非法区间显示错误并保留输入供修改。

- 导航：四类切换后恢复各自条件，更多条件支持外部点击、Esc 和关闭按钮；关闭浮层不会同时关闭设备选择弹窗，并恢复按钮焦点。
- 布局：1520 × 960、1280 × 800、1000 × 720 下验证列表滚动、分页、详情和加入按钮。详情标题与规格一起滚动，底部加入按钮固定；翻页主动回到列表顶部。
- 文字适配：区间显示单位、上下限和公开范围，已选条件可单项移除；未公开字段不会被当作零值。窄窗口导航图标保留可访问名称。
- 视觉检查：使用独立预览数据库和 4,844 条真实内置资料核对四类界面、更多条件与窄窗口截图；沿用当前高对比度石墨主题，控件边界、选中条件及结果数量清晰可见，无页面水平溢出。

验证通过：Rust 核心 40 项、桌面导出 3 项、前端单元 9 项；真实 API 交互 24 项整体通过后，详情滚动补强检查与底部留白修正再次通过全部 6 项筛选回归。Rust 格式、Clippy、TypeScript、前端构建、Prettier 及 UTF-8 检查通过。

实际 Windows 桌面使用独立数据库和 WebView2 目录，验证规格输入触发 Rust 筛选、无结果状态、清空恢复、更多条件展开收起及窗口关闭；只操作验证脚本自行启动的进程。预览未发生页面错误，原始硬件文件未修改。

内置资料样例：相机选择 USB3、黑白、5–12 MP、至少 30 fps，匹配 64 / 1,393 条；增加全局快门后匹配 45 条。3D 相机选择线激光轮廓、至少 1,000 Hz 并支持编码器，匹配 165 / 267 条。
